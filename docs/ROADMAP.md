## What v1.0.0 Will Include

- Desktop GUI — manage everything without touching config files
- Plugin opt-in model — enable only what you need
- Timer, Death Counter, Win Counter fully decoupled
- Unified API server — one port instead of a dozen
- First-run setup wizard
- Live log viewer and server dashboard
- Overlay preview with theme editor
- Spotify setup assistant
- Integrated trigger testing
- Much fewer ports (3–4 instead of 12+)
- **GUIDE.md rewritten** — screenshots, setup wizard walkthrough, new quick-start
- **Developer documentation rewritten** — dev-book EN + DE updated for the new API and plugin architecture

**⚠️ v1.0.0 breaks with v0.x.** Configs, plugins, and workflows from
previous versions will not be compatible. This is a deliberate clean break.

---

## What v1.0.0 Will NOT Include

- Twitch / YouTube support (the tool remains TikTok-focused)
- Mobile app
- Cloud features
