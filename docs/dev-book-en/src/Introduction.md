# Introduction

TikTok2Mc connects TikTok Live events with Minecraft. This documentation is aimed at developers who want to write their own extensions.

## Extension Options

- **Plugins** — Standalone subprocesses with HTTP API, GUI, and state management
- **Hooks** — Lightweight, in-process `$` commands for `actions.mca`

## Structure

1. **Quickstart** (5 minutes) — Your first plugin up and running
2. **Plugin Development** — Complete guide with API reference
3. **Hook Development** — `$` commands for Minecraft actions
4. **Actions & Minecraft** — `actions.mca`, Event-Command-Mapper, RCON, Overlay

## Prerequisites

- Python 3.12+
- Basic knowledge of Python
- Basic terminal knowledge
- Installed TikTok2Mc
