# Plugin-Entwicklung

Plugins sind der primäre Weg, um TikTok2Mc zu erweitern. Ein Plugin ist ein eigenständiges Programm, das als separater Prozess läuft und über eine HTTP-API mit dem Hauptsystem kommuniziert.

In diesem Kapitel lernst du alles, was du brauchst, um eigene Plugins zu entwickeln – von der ersten Idee bis zur produktionsreifen Implementierung.
