# Plugin-Entwicklung

Plugins sind der primäre Erweiterungsmechanismus. Ein Plugin läuft als separater Subprozess und kommuniziert per HTTP mit dem API-Server.

In diesem Kapitel entwickelst du Schritt für Schritt ein vollständiges Plugin. Jedes Kapitel baut auf dem vorherigen auf.
